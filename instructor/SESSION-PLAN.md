# Instructor session plan

**Audience:** Incoming graduate students, including GitHub beginners.

**Duration:** 30–45 minutes (40-minute default).

| Minutes | Segment | Student outcome |
| --- | --- | --- |
| 0–5 | Review a research-oriented GitHub profile | Identify useful sections |
| 5–11 | Create profile repository | Public username-matching repository |
| 11–20 | Write introduction in Markdown | Published profile README |
| 20–28 | Add a project and badge | One substantive enhancement |
| 28–37 | Independent design practice | Personalized, tested profile |
| 37–40 | Review and troubleshooting | Verified public profile URL |

For 45 minutes, extend peer review. For 30 minutes, shorten the case study and independent work.

**Live demonstration:** Show the difference between the workshop repository and the special username-matching profile repository. Demonstrate GitHub's Edit, Preview, and Commit interface.

**Teaching priorities:** Accurate claims, clear hierarchy, accessibility, privacy, and maintainability. Do not require students to invent projects.

**Presentation:** The unfinished slide deck is excluded. Add only the final reviewed deck under `slides/`.
