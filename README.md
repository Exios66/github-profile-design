# GitHub Profile Design Studio

A **hands-on GitHub profile README workshop** for incoming graduate students, inspired by the [Exios66 GitHub profile](https://github.com/Exios66).

**Workshop duration:** 30–45 minutes live; the materials are designed to work as a self-paced reference afterward.

> This is the **workshop resource repository**. To make your *own* GitHub profile README appear on your profile, create a separate **public repository named exactly your GitHub username**, containing a root-level `README.md`.

## Start here

1. Read [the getting-started guide](guides/00-start-here.md).
2. [Create your profile repository](guides/01-create-profile-repository.md).
3. Pick a [starter](templates/README-starter.md) or [research-focused](templates/README-research.md) template.
4. Add a [badge](snippets/02-static-badges.md), [project showcase](snippets/03-project-showcase.md), or [responsive banner](guides/05-svg-responsive-themes.md).
5. Use the [review checklist](CHECKLIST.md) before sharing.

## Workshop agenda

| Time | Activity |
| --- | --- |
| 0–5 min | Why a strong GitHub profile matters; case study |
| 5–11 min | Create the username-matching repository |
| 11–20 min | Markdown fundamentals and academic introduction |
| 20–28 min | Projects, links, and purposeful badges |
| 28–37 min | Personalize and test |
| 37–45 min | Peer review, troubleshooting, next steps |

For a 30-minute session, shorten the case study and independent practice.
