# Student profile publication checklist

- [ ] My profile repository is public and matches my GitHub username exactly.
- [ ] Its root `README.md` appears on my profile.
- [ ] My introduction explains my field and interests.
- [ ] My featured work or learning goal is represented accurately.
- [ ] All links and images work.
- [ ] No template placeholders remain.
- [ ] The page is readable in light/dark modes and on a narrow screen.
- [ ] Badges and visuals add meaning rather than clutter.
- [ ] No secrets, confidential research, or unwanted personal information are exposed.
- [ ] I can explain and maintain everything on the page.
