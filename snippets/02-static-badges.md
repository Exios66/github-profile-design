# Badge snippet library

## Technology badge

```markdown
![Python](https://img.shields.io/badge/Python-Programming-3776AB?logo=python&logoColor=white)
```

## Clickable GitHub badge

```markdown
[![GitHub](https://img.shields.io/badge/GitHub-Projects-181717?logo=github&logoColor=white)](https://github.com/YOUR_USERNAME)
```

## Research interest badge

```markdown
![Research](https://img.shields.io/badge/Research-Data%20Science-4051B5)
```

Replace usernames and labels, test each URL, and limit badges to those that communicate useful information. [Shields.io](https://shields.io/) provides documentation and customization options.
