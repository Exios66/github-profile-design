# 02 — Markdown foundations

GitHub profile READMEs use GitHub Flavored Markdown.

```markdown
# Your name
## Research interests

I study **machine learning** and *human-computer interaction*.

- Current project: explain it in one sentence
- Learning: a real skill you're developing

[My projects](https://github.com/YOUR_USERNAME)

![Accessible description](https://example.com/your-image.png)
```

**Useful building blocks:** headings, short paragraphs, bullets, links, images, and code fences. Preview before committing.

Avoid deeply nested HTML, giant animated graphics, or layouts that only work on wide screens. GitHub sanitizes some HTML and CSS; ordinary Markdown is usually more robust.

**Practice:** Write a two-sentence introduction, three concise bullets, and one verified link.
