# 00 — Start here

**Goal:** Publish a useful, readable GitHub profile in one sitting.

You need a GitHub account, a web browser, and a short description of your interests. No terminal, Git experience, or paid services are required.

Follow these lessons in order:

1. [Create the profile repository](01-create-profile-repository.md)
2. [Learn Markdown foundations](02-markdown-foundations.md)
3. [Tell your academic story](03-academic-story.md)
4. [Add badges with intention](04-badges-design.md)
5. [Try SVG and responsive themes](05-svg-responsive-themes.md)
6. [Check accessibility and maintainability](06-quality-check.md)

Use the [starter template](../templates/README-starter.md) and finish with the [checklist](../CHECKLIST.md). All examples contain placeholders that you must replace with accurate information.
