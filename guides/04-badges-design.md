# 04 — Badges and visual design

Badges are small visual labels. Use them for real technologies, destinations, or project status—not as decoration alone.

## Static Shields.io badge

```markdown
![Python](https://img.shields.io/badge/Python-Programming-3776AB?logo=python&logoColor=white)
```

## Linked badge

```markdown
[![GitHub](https://img.shields.io/badge/GitHub-Projects-181717?logo=github&logoColor=white)](https://github.com/YOUR_USERNAME)
```

Use a restrained palette, readable contrast, consistent labels, and sensible spacing. Badges depend on an external image provider and may temporarily fail to render.

See [the copy-paste badge library](../snippets/02-static-badges.md).
