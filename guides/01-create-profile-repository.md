# 01 — Create your GitHub profile repository

1. Sign in to GitHub and note your **exact username**.
2. Go to [New repository](https://github.com/new).
3. Set the **repository name** to your exact username, including capitalization as appropriate. Example: user `octocat` creates `octocat/octocat`.
4. Choose **Public**.
5. Check **Add a README file** and create the repository.
6. Edit the root `README.md`, preview it, and commit changes.
7. Open `https://github.com/YOUR_USERNAME` to verify it displays on your profile.

The special profile README only works for a public repository with the matching name and a root README. This teaching repository does not replace that requirement.

**Troubleshooting:** If your profile does not show the README, check visibility, repository spelling, filename, and whether you committed the change.
