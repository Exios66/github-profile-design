# Exercise 1 — Ten-minute profile

**Outcome:** A public profile README with an accurate introduction.

1. Create a public repository matching your username.
2. Initialize its root README.
3. Copy the [starter template](../templates/README-starter.md).
4. Replace all placeholders.
5. Commit and verify the profile at `github.com/YOUR_USERNAME`.

**Done when:** Your introduction appears on your public profile and the README has no placeholders or broken links.

**Stretch:** Add one purposeful badge from [the badge snippets](../snippets/02-static-badges.md).
