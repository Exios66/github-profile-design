# Exercise 3 — Extended independent lab

**Time:** 20–30 minutes outside the live workshop.

Choose two extensions:

- Add a detailed project description with problem, approach, and outcome.
- Create a simple SVG banner with accessible alternative text.
- Document a reproducible research project.
- Audit and repair every external link.
- Ask a peer for a usability review and revise your profile.

**Deliverable:** Your public GitHub profile URL and a short description of the changes you made.
